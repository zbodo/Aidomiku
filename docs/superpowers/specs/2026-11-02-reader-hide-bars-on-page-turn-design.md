# 阅读器翻页时隐藏栏设计

## 目标

将现有“滑动时隐藏栏”选项扩展为“翻页时隐藏栏”。选项开启后，滑动、硬件键盘和 Apple Pencil 触发的翻页都隐藏阅读器顶部导航栏与底部工具栏。

## 行为

- 滑动翻页继续在选项开启时隐藏栏。
- 左、右、上、下、Page Up 和 Page Down 键翻页时，在选项开启时隐藏栏。
- Apple Pencil 挤压触发上一页或下一页时，在选项开启时隐藏栏。
- 点击左右翻页区域维持现状，无论选项是否开启都隐藏栏。
- 使用底部页码滑块跳页时不隐藏栏，避免操作中的工具栏消失。
- 空格切换栏、章节切换和其他快捷键行为保持不变。

## 实现

保留偏好键 `Reader.hideBarsOnSwipe` 及其默认值，确保已有用户设置继续生效。设置界面的本地化文案改为“翻页时隐藏栏”语义。

在 `ReaderViewController` 的共用离散翻页入口检查该偏好：选项开启时先调用现有 `hideBars()`，再将翻页动作转发给当前阅读器。键盘和 Apple Pencil 复用这些入口。各阅读器现有的滑动回调与点击翻页逻辑保持不变。

## 验证

1. 选项开启时，验证六个翻页键都会隐藏栏并正常翻页。
2. 选项开启时，验证 Apple Pencil 上一页和下一页操作都会隐藏栏。
3. 选项关闭时，验证键盘和 Apple Pencil 翻页不会主动隐藏栏。
4. 验证滑动翻页仍受该选项控制。
5. 验证点击左右翻页区域仍始终隐藏栏，页码滑块操作期间栏保持可见。
6. 验证设置标题使用“翻页时隐藏栏”语义，并保留已有偏好值。
